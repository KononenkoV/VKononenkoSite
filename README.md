# Сайт-визитка Вадима Кононенко

Одностраничный сайт: обо мне, опыт работы, портфель проектов, навыки, контакты.

## Стек

Чистые HTML, CSS и JavaScript. Ни фреймворков, ни сборки, ни зависимостей —
`index.html` открывается как есть. Шрифты подключаются с Google Fonts.

```
index.html      разметка страницы целиком
styles.css      стили
script.js       карусель проектов, аккордеон опыта, облако тегов, анимации появления
assets/         фотографии, скриншоты кейсов, награды, PDF
robots.txt      открыт для поисковых и ИИ-краулеров
sitemap.xml     карта сайта
llms.txt        выжимка для языковых моделей
```

## Локальный запуск

```
python3 -m http.server 8000
```

Затем открыть http://localhost:8000 — сервер нужен только потому, что часть
ресурсов подгружается относительными путями.

## Публикация

Статика из корня репозитория, сборка не требуется.

После привязки домена заменить `https://example.com/` в `sitemap.xml` на
реальный адрес и раскомментировать строку `Sitemap:` в `robots.txt`.
Тег `canonical` в `index.html` относительный и правок не требует.
